# diaries/

Put your Day Tracker JSON data file(s) here (e.g. `day-tracker-data.json`).

This folder isn't created or targeted automatically by the app — point the
Open/Create pickers in here once (or use "Set project folder…" and pick
this folder) and the browser/app will remember it for next time. See
CLAUDE.md, section "Jumping straight to a folder you use often".
